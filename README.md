# Tidy Grove — Five-Page Small Business Website Demo

A responsive, accessible, front-end portfolio demonstration for a **fictional home-organizing business**. Created to showcase the design and website-development services offered by CLS.

## Pages
- **Home** (`index.html`): Hero, service previews, brand story, process, call to action.
- **Services** (`services.html`): Three illustrative service tiers, interactive estimate calculator, FAQ.
- **About** (`about.html`): Brand narrative and values.
- **Our Work** (`work.html`): Six inspiration-image cards, clearly labeled **concepts** rather than client work.
- **Contact** (`contact.html`): Validated sample inquiry form with copy-to-clipboard behavior and graceful fallback (no backend, no message sending or storage).

## Features
- Responsive desktop, tablet, and mobile layouts with collapsible navigation.
- Semantic landmarks, keyboard-friendly controls, skip-to-content link, form labels, visible focus states, accessible status feedback, and reduced-motion support.
- Interactive JavaScript price estimator with explicitly **illustrative** pricing.
- Reusable CSS design system, consistent cards/buttons, and basic SEO metadata.
- No build process, framework, API key, tracking, or paid hosting required.

## Run locally
Open `index.html` in a browser, or serve the folder with `python -m http.server 8000` and visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Create a **public** GitHub repository named `tidy-grove-website-demo`.
2. Upload all the files, with the stylesheet, script and icon at the repository root; `index.html` must be at the root.
3. In **Settings > Pages**, choose **Deploy from a branch**, `main` and `/ (root)` and save.
4. When the deployment finishes, the demo will be available at `https://YOUR_USERNAME.github.io/tidy-grove-website-demo/`.
